Nova impressora

Linguagem
Conexão

No Linux, a porta virtual aparece como /tmp/bobina-…; configure o sistema nela. No Windows, crie um par com o com0com (ex.: COM10 e COM11), escolha uma aqui e use a outra no sistema.

Cada arquivo que aparecer nessa pasta é impresso e movido para a subpasta impressos.

O sistema também pode trocar o conjunto com o comando GS F9 da Bematech; quando ele pede para gravar, a impressora passa a ligar nesse modo.
